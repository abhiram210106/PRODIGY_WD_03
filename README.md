# 🎮 PRODIGY_WD_03 Tic-Tac-Toe Web Application

## 📌 Prodigy InfoTech Web Development Internship — Task 3

An interactive **Tic-Tac-Toe Web Application** developed using **HTML, CSS, and JavaScript** as part of the Prodigy InfoTech Web Development Internship.

The application provides a responsive and interactive game interface where players can take turns and play Tic-Tac-Toe directly in the browser.

## 🎯 Task Objective

Build an interactive Tic-Tac-Toe web application using HTML, CSS, and JavaScript.

The application should allow users to interact with the game board, track player turns, detect winning combinations, and restart the game.

## ✨ Features

- 🎮 Interactive 3×3 Tic-Tac-Toe board
- ❌ Player X and Player O turns
- 🔄 Automatic turn switching
- 🏆 Win detection
- 🤝 Draw detection
- 🔁 Restart / New Game functionality
- 🖱️ Interactive cell selection
- 📱 Responsive user interface
- 🎨 Modern and visually appealing design
- ⚡ Dynamic game updates using JavaScript

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, layout, animations, and responsive design
- **JavaScript** — Game logic, player turns, win/draw detection, and user interaction
